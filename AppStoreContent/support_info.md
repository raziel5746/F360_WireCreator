# Wire Creator - Support Information

## Contact

**Email:** raz.mobility888@passmail.com

## Support Hours

We typically respond to support requests within 48 hours during business days.

## Before Contacting Support

Please try the following:

1. **Check you're using the latest version of Fusion 360**
2. **Restart Fusion 360** and try running the add-in again
3. **Check the help documentation** included with the add-in

## When Reporting Issues

Please include:

- Your Fusion 360 version number
- Your operating system (Windows 10/11 or macOS version)
- A description of what you were trying to do
- The exact error message (if any)
- Screenshots if helpful

## Feature Requests

We welcome feature requests! Please email us with:

- A description of the feature you'd like
- How it would help your workflow
- Any examples or mockups if applicable
