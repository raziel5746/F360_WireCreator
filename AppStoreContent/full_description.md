# Wire Creator for Fusion 360

Wire Creator is a powerful add-in that simplifies the process of creating wires, cables, tubes, and conduits between two circular profiles in Fusion 360. With just two clicks, you can generate smooth, professional-looking connections that would otherwise require multiple manual steps.

## Key Features

### 🔌 Easy Profile Selection
Select any two circular edges or cylindrical faces, and Wire Creator automatically detects the geometry and orientation.

### 🎯 Smart Geometry Detection
- Works with circular edges (holes, cylinders)
- Works with cylindrical and conical faces
- Works with planar circular faces
- Automatic center point and normal detection

### ⚡ Instant Preview
See your wire in real-time as you adjust settings before committing to the final geometry.

### 🔄 Flip Direction Controls
Independent flip controls for each profile let you easily correct the wire direction when needed.

### 📐 Center Point Offset
Adjust the curvature of your wire with the Center Point Offset parameter:
- Positive values create a bow/droop effect
- Negative values create an arc in the opposite direction
- Automatically scales based on profile orientation

### 🎨 Clean Solid Geometry
Creates proper solid loft geometry using a spline centerline with tangent handles perpendicular to your selected profiles.

## Use Cases

- **Electronics Design**: Route wires between connectors, terminals, and PCB headers
- **Cable Management**: Design cable runs in enclosures and equipment
- **Plumbing & HVAC**: Create tube and conduit runs
- **Mechanical Assemblies**: Add flexible connections between components
- **Automotive & Aerospace**: Model wiring harnesses and fluid lines

## How It Works

1. Run the Wire Creator command from the Add-ins panel
2. Select the first circular edge or face
3. Select the second circular edge or face
4. Adjust the Center Point Offset for desired curvature
5. Use Flip checkboxes if needed to correct direction
6. Click OK to create the wire

## System Requirements

- Autodesk Fusion 360 (latest version recommended)
- Windows 10/11 or macOS
