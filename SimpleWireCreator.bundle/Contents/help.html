Simple Wire Creator for Fusion 360

Simple Wire Creator helps you quickly create wires, cables, and tubes between two circular profiles using a smooth loft operation.

Quick Start Guide

Step 1: Open a design with circular edges or faces (such as holes or cylindrical features).
Step 2: Go to UTILITIES → Add-Ins → Scripts and Add-Ins, find Simple Wire Creator, and click Run.
Step 3: Click on the first circular edge or face where you want the wire to start.
Step 4: Click on the second circular edge or face where you want the wire to end.
Step 5: Adjust the Center Point Offset to control how much the wire curves.
Step 6: If needed, use the Flip checkboxes to adjust the orientation of the wire ends.
Step 7: Click OK to create the wire geometry.

Parameters

First Profile / Second Profile

Select circular edges or faces (other profile shapes are also supported).

Flip

Each profile has a Flip checkbox. Use this to reverse the direction of the wire at that end if it's going the wrong way.

Center Point Offset

Controls the curvature of the wire:

  • Positive values: Creates a bow/droop in the direction determined by profile orientations
  • Negative values: Creates a curve in the opposite direction
  • Zero: Creates a straight connection (when profiles face each other)
The curvature automatically scales based on how the profiles are oriented relative to each other. When profiles face directly toward each other, the offset has minimal effect.

Tips for Best Results

  • For the smoothest wires, select profiles that are roughly the same size
  • The preview updates in real-time as you adjust settings
  • If the wire looks twisted, try using the Flip checkboxes
  • The wire is created as a solid body that you can modify further
After the wire is created, you can use the Move tool to adjust the points and handles of the sketch curve. This is especially useful for fine-tuning the shape of the wire by moving the center point of the curve.

Troubleshooting

Wire goes in wrong direction

Use the Flip checkbox for the profile that needs correction.

"Profiles are too close" error

The selected profiles are nearly coincident. Select profiles that are further apart.

Loft fails

This can happen if the profiles have very different sizes or if the curvature causes self-intersection. Try increasing the Center Point Offset value.
